File upload history

Recent files uploaded via requests that call pm.fileHistory.add(). The most recently added file is always available as {{docTempFileId}} in any request.

Example: track an uploaded temp file

How to save an uploaded file's id and reuse it in other requests.

1. Body → form-data

KeyTypeValue
dataFile(attached file)
mimeTypeTextapplication/pdf
nameTexttest.pdf

2. Scripts → Post-response

const r = pm.response.json();
pm.environment.set("docTempFileId", r.id);
pm.fileHistory.add({ id: r.id, name: r.name, mimeType: r.mimeType });

After this, the file's id is available as {{docTempFileId}} in any other request — the most recently uploaded file is filled in automatically unless the variable is set manually. View the full history of uploaded files with the 📎 button in the header.
